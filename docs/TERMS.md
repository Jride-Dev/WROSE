# WROSE Sentinel Terms and Conditions

Last updated: May 26, 2026

## 1. Overview

WROSE Sentinel is a Reddit-native moderator support tool for the WROSE project, short for Working Reddit Operational Signal Engine.

WROSE Sentinel is designed to help moderators review subreddit activity patterns, thread volatility, activity spikes, replay signals, and other operational indicators.

WROSE Sentinel is an analytical tool. It does not replace moderator judgment.

## 3. Intended Use

WROSE Sentinel is intended for moderator-support workflows, including:

- reviewing thread activity
- checking volatility signals
- identifying activity spikes
- viewing explainable signal summaries
- supporting moderator awareness

WROSE Sentinel is not intended to be used for harassment, profiling, doxxing, political labeling, user targeting, or automated punishment.

## 4. No Automated Moderation Actions

WROSE Sentinel does not automatically:

- remove posts
- remove comments
- lock threads
- ban users
- mute users
- report users
- approve content
- distinguish content
- modify Reddit content

All outputs are informational only.

Every analysis response is expected to preserve the safety invariant:

`automated_action_taken: false`

Moderators remain responsible for any moderation decisions they choose to make.

## 5. No Individual Profiling

WROSE Sentinel is designed around subreddit-level and thread-level operational signals.

The app is not designed to diagnose, classify, or predict individual users.

WROSE Sentinel does not claim to determine user intent, truthfulness, political beliefs, mental health status, or future behavior.

## 6. Data Use

WROSE Sentinel may process Reddit content and metadata available to the app through Reddit-approved interfaces and permissions.

This may include:

WROSE Sentinel should not be used to collect or sell personal profiles.
